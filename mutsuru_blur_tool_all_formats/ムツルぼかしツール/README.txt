ムツルぼかしツール

画像の読み込み
・PNG / JPG / JPEG / WebP / GIF / BMP / AVIF / SVG など、ブラウザが表示できる画像形式に対応します。
・HEIC / HEIF は読み込み時にブラウザ内でJPEGへ変換します（初回変換にはインターネット接続が必要です）。
・TIFFなど、ブラウザや環境によって表示できない形式は読み込めない場合があります。RAWなどのカメラ専用形式は、事前にJPG/PNGへ変換してください。
・アニメーションGIFは静止画として読み込まれます。

使い方
1. index.html を Google Chrome または Microsoft Edge で開きます。
2. 写真を読み込みます。ドラッグ＆ドロップにも対応しています。
3. 顔・人物の自動検出、または画像上をドラッグして加工範囲を追加します。
4. 加工方法、形、強さ・サイズ、範囲の拡大・縮小を調整します。
5. 「JPGで保存する」を押すと、最終画像は必ずJPG形式で保存されます。

補足
・画像の編集と書き出しはブラウザ内で行います。
・HEIC変換とAI顔/人物検出の初回利用時はインターネット接続が必要です。
・検出結果は必ず確認し、隠し漏れがあれば加工範囲を追加してください。
